# Odin-Landing-Page

A simple landing page website built as part of the 
**[<u>The Odin Project Foundations Course</u>](https://www.theodinproject.com/lessons/foundations-landing-page)**.
This project focuses on practicing the fundamentals of **HTML and CSS**, with a particular emphasis on creating clean layouts using CSS Flexbox.

The goal of this project is to take a basic design concept and turn it into a structured,
visually appealing webpage while getting hands-on experience with common CSS styling techniques.

## Purpose

This project is mainly focused on strengthening my CSS and Flexbox fundamentals through practical implementation rather than just learning the concepts theoretically.

## Design Reference

This project was built using the design provided by **The Odin Project** as a visual reference. I followed the provided layout, colors, fonts, and sizing guidelines while building the landing page.
